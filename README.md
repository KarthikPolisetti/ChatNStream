# ChatNStream

A robust real-time communication platform designed to seamlessly connect users through instant messaging and high-quality video calling. 

## Key Features

*   **Real-Time Chat:** Instantaneous message delivery and reception for fluid conversations.
*   **Video Calling:** Integrated, high-quality video communication capabilities.
*   **Scheduled Messaging:** A unique functionality allowing users to compose messages and schedule them for future automated delivery.

## Tech Stack

*   **Frontend:** React
*   **Backend:** Node.js
*   **Infrastructure:** Stream.io

---

## Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

Ensure you have Node.js and npm installed. You will also need a Stream.io developer account to obtain the necessary API keys for the communication infrastructure.

### Installation Steps

1.  Clone the repository using `git clone https://github.com/KarthikPolisetti/ChatNStream.git`
2.  Navigate into the project's root directory.
3.  Install the required dependencies using `npm install`.
4.  Create a `.env` file in the root directory.
5.  Populate the `.env` file with your specific credentials (see the Environment Variables section below).
6.  Start the development server using `npm start` or `npm run dev`.

### Environment Variables

| Variable Name | Description |
| :--- | :--- |
| `PORT` | The port your backend server will run on (e.g., 5000) |
| `STREAM_API_KEY` | Your Stream.io application API key |
| `STREAM_API_SECRET` | Your Stream.io application API secret |
| `STREAM_APP_ID` | Your Stream.io application ID |
